CryptoDash

Dashboard de monitoramento de criptomoedas desenvolvido para acompanhar Bitcoin, Ethereum e Solana através de dados de mercado, gráficos históricos e diferentes moedas de referência.

HTML5 CSS3 JavaScript Bootstrap Chart.js
01

Sobre o Projeto

O CryptoDash é um dashboard frontend criado para apresentar informações de mercado de criptomoedas de forma visual e organizada. A aplicação acompanha Bitcoin, Ethereum e Solana, permitindo ao usuário alternar entre diferentes ativos e acompanhar seus respectivos dados.

Os dados são obtidos através da CoinGecko API, incluindo preço, variação nas últimas 24 horas, volume de negociação e capitalização de mercado. O projeto também apresenta gráficos históricos utilizando a biblioteca Chart.js.

A interface permite alternar entre Dólar, Euro e Real, além de selecionar diferentes períodos e intervalos para análise dos gráficos. Também existe um conversor entre moedas fiduciárias e criptomoedas, juntamente com uma visualização de valores em Satoshi.

02

Funcionalidades

Monitoramento de Criptomoedas

Acompanhamento de Bitcoin, Ethereum e Solana através de dados atualizados da API.

Gráficos Históricos

Visualização da evolução dos preços através de gráficos interativos com Chart.js.

Diferentes Moedas

Consulta dos valores em USD, EUR e BRL, facilitando a leitura dos preços.

Atualização Automática

Os dados são atualizados automaticamente enquanto o dashboard permanece aberto.

Períodos e Intervalos

Seleção do período e intervalo utilizado na visualização dos dados históricos.

Conversor de Moedas

Conversão entre moedas fiduciárias e criptomoedas disponíveis no dashboard.

03

Desenvolvimento

O projeto foi desenvolvido como uma aplicação frontend, utilizando HTML, CSS e JavaScript para construir a estrutura, o comportamento e a apresentação visual do dashboard.

O Bootstrap 5.3 foi utilizado como base para componentes e responsividade da interface, enquanto o Chart.js 3.9.1 ficou responsável pela renderização dos gráficos.

A integração com a CoinGecko API permite consultar informações de preço, variação, volume e capitalização de mercado. As consultas de histórico também alimentam os gráficos de acordo com o ativo, período e intervalo selecionados.

O projeto também trabalha com atualização periódica: os dados principais são atualizados a cada 30 segundos, enquanto os gráficos são atualizados a cada 2 minutos.

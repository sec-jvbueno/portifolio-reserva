Sobre o projeto

Uma presença digital para a Multishop

O Multishop foi desenvolvido como uma landing page voltada para uma loja de perfumaria, com o objetivo de apresentar a marca e facilitar a divulgação de seus principais produtos.

A estrutura da página foi pensada para destacar diferentes categorias de interesse do público, como os produtos mais vendidos, opções com preços mais acessíveis e novidades da loja.

Além da apresentação comercial, a página também possui recursos voltados ao relacionamento com os clientes, permitindo o envio de informações de contato e o cadastro de interessados em promoções.

Funcionalidades

Estrutura pensada para divulgação

Produtos em destaque

Espaços destinados à apresentação dos produtos mais relevantes para os clientes.

Mais vendidos

Destaque para os produtos de maior interesse e procura dentro da loja.

Ofertas

Área para divulgação de produtos com preços mais acessíveis e oportunidades promocionais.

Novidades

Destaque para novos produtos e atualizações relevantes da loja.

Contato

Formulários para que visitantes possam entrar em contato com o responsável pela loja.

Cadastro em promoções

Cadastro de interessados para ações e campanhas promocionais da loja.

Desenvolvimento

WordPress com abordagem Low Code

WordPress

Plataforma de gerenciamento

O projeto foi construído utilizando WordPress como plataforma principal, permitindo estruturar e administrar o conteúdo da landing page de maneira prática e eficiente.

Elementor Pro

Construção visual da interface

O Elementor Pro foi utilizado para construir visualmente as seções da página, permitindo desenvolver a interface e organizar os componentes da landing page com uma abordagem Low Code.

MySQL

Armazenamento de dados

O banco de dados MySQL é utilizado para armazenar informações relacionadas aos clientes que entram em contato com a loja e aos usuários cadastrados em campanhas promocionais.

Objetivo do projeto

Criar uma presença digital profissional para a Multishop, utilizando uma landing page objetiva e visualmente atrativa para apresentar produtos, divulgar novidades, destacar ofertas e facilitar o relacionamento com potenciais clientes.

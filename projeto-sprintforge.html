Interface da plataforma

Sobre o Projeto

O SprintForge é uma plataforma de gerenciamento de projetos inspirada principalmente em metodologias ágeis como Scrum e Kanban.

O projeto nasceu com o objetivo de criar uma solução própria para organizar o ciclo completo de desenvolvimento de software, permitindo acompanhar projetos, tarefas, sprints e indicadores de evolução em um único ambiente.

Além da gestão tradicional de tarefas, a plataforma possui recursos voltados para acompanhamento de produtividade, evolução por XP, análise de métricas, maturidade ágil e suporte através de um assistente baseado em inteligência artificial.

A aplicação foi construída como um projeto autoral Full Stack e está sendo desenvolvida pensando em uma futura evolução para um produto SaaS.

Principais funcionalidades

Dashboard

Visão geral do projeto, tarefas, progresso, indicadores e principais informações da equipe.

Kanban

Organização visual do fluxo de trabalho através de colunas e movimentação de tarefas.

Scrum

Gerenciamento de Product Backlog, Sprint Backlog, sprints e fluxo de desenvolvimento.

Sistema de XP

Sistema de experiência para acompanhar evolução, produtividade e progresso dos usuários.

Analytics

Métricas e indicadores para analisar o desempenho e evolução dos projetos.

Assistente Ágil

Assistente voltado para apoiar decisões e dúvidas relacionadas ao desenvolvimento ágil.

Maturidade Ágil

Recursos destinados a acompanhar o nível de maturidade dos processos ágeis utilizados pelo projeto e pela equipe.

Desenvolvimento

O frontend foi desenvolvido utilizando React + TypeScript, com Tailwind CSS para construção da interface.

O backend utiliza Node.js e Express, responsável pelas APIs e regras de negócio da aplicação.

A persistência dos dados é realizada utilizando PostgreSQL, com Prisma ORM para comunicação entre a aplicação e o banco de dados.

A arquitetura foi estruturada pensando em escalabilidade e na possibilidade de transformar a aplicação em um produto SaaS no futuro.

Tecnologias

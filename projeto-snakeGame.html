Snake Game

Uma releitura moderna do clássico Snake, desenvolvida com tecnologias web e diferentes níveis de desafio, fases e mecânicas de progressão.

Visão geral

Sobre o Projeto

O Snake Game é uma releitura do clássico jogo de cobra, desenvolvida para navegador com foco em lógica de programação, interação com o usuário e progressão de dificuldade.

O projeto utiliza JavaScript puro para controlar a movimentação, colisões, pontuação e regras da partida, enquanto o Canvas API é utilizado para a renderização do jogo.

A proposta vai além de uma partida tradicional: o jogador pode escolher entre diferentes fases e níveis de dificuldade, avançando progressivamente conforme supera os desafios.

Funcionalidades

Principais Recursos

10 fases

Progressão por diferentes fases com desafios que aumentam conforme o jogador avança.

5 dificuldades

Modos Fácil, Normal, Difícil, Muito Difícil e Impossível.

Sistema de pontuação

A partida acompanha a pontuação do jogador durante o desenvolvimento da fase.

Pausa e continuação

O jogador pode pausar e continuar a partida utilizando os comandos disponíveis.

Controles por teclado

Interação baseada em comandos de teclado para controlar diretamente a movimentação do personagem.

Reinício de partida

Após o fim da partida, o jogador pode reiniciar o desafio e tentar novamente.

Desenvolvimento

Construção do Projeto

O desenvolvimento foi realizado utilizando HTML5, CSS3 e JavaScript, sem a necessidade de um framework ou backend para executar a experiência principal do jogo.

A lógica central envolve controle de eventos do teclado, movimentação da cobra, detecção de colisões, atualização da pontuação, gerenciamento das fases e controle dos diferentes níveis de dificuldade.

A renderização através do Canvas API permite atualizar visualmente o estado do jogo em tempo real, mantendo a aplicação inteiramente executada no navegador.

Tecnologias

HTML5 CSS3 JavaScript Canvas API
